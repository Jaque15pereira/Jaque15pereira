# Projeto "Como organizar sua vida Financeira com Planilhas Inteligentes e IA"

----------------
Projeto com o objetivo de gerar um dashboard para organização da vida financeira utilizando uma planilhas inteligentes do EXCEL.

## 💻 Tecnologias utilizadas no projeto

- Microsoft Excel
- Google 

## ✨ Como foi feito ?

- Base de dados gerados em tabela no EXCEL
- Tabelas dinâmicas, Gráficos e Dashboard gerados no EXCEL
- Ilustrações e ícones gerados com as funcionalidades do EXCEL
- Imagem da Boneca obtida no Google


## 🛠️ Execução

Utilizei as ferramentas disponíveis no Excel fornecido na parte de `Tecnologias utilizadas no projeto para criar um Dashboard, utilizando o passo a passo abaixo.
- 🤖 1. Usei a ferramenta iserir Tabela Dinâmica para gerar as informações a partir dos dados disponibilizados com as entradas e saídas no "excel"
- 🤖 2. Usei a ferramenta iserir Gráficos Recomendados para gerar um gráfico das informações obtidas na tabela dinâmica no "excel"
- 🤖 3. Usei a ferramenta iserir Nova Planilha e modelei através de um dashboard as informações obtidas nas tabelas dinâmicas e gráficos no "excel"
